- **应用编排**：以 `config.ru` 为入口启动 Rails 应用，集成 Grape API 框架提供 RESTful 接口，并通过 Puma 作为高性能 Web 服务器。
- **基础设施集成**：通过 `docker-compose.yml` 在开发环境编排 MySQL 数据库与应用容器，生产环境则依赖阿里云 RDS 与自建 Registry。
- **部署流水线**：采用 Kamal 进行容器化部署，利用多阶段 Dockerfile 优化镜像体积，并通过 `bin/docker-entrypoint` 统一处理数据库迁移 (`db:prepare`) 与服务启动。
- **配置管理**：敏感信息通过 `.kamal/secrets` 隔离，环境变量在部署时注入容器，确保开发与生产环境的配置一致性与时区同步 (`TZ: Asia/Shanghai`)。
