- **分层架构与路由挂载**：采用标准的 MVC 结构，`controllers/api/` 下的各子模块（如 `app_users`, `books`）通过独立的 `mount.rb` 文件将路由挂载至主应用，实现功能模块的物理隔离与逻辑解耦。
- **领域服务与异步解耦**：复杂业务逻辑（如支付回调、电子书导入）下沉至 `services/` 和 `workers/`，通过 Sidekiq 等后台任务处理耗时操作，确保 API 接口的快速响应。
- **数据实体抽象**：在 `entities/` 层定义轻量级数据传输对象（DTO），用于解耦底层 ActiveRecord 模型与上层 API 响应结构，提供统一的数据视图。
