- **API 架构**：基于 `Grape::API` 构建，通过 `Api::Config` 定义全局 JSON 格式与异常拦截（`rescue_from`），由 `Api::Base` 作为入口挂载各业务子模块并集成 Swagger 文档。
- **辅助模块**：在 `app/controllers/api/concerns/` 中封装 `CommonHelpers`（统一响应结构、分页、API 签名认证）和 `SmsHelpers`（短信验证码逻辑），供各接口复用。
- **异常体系**：定义 `Api::Errors::CommonError` 及其子类（如 `AuthenticationError`, `ValidationError`），实现业务错误码与 HTTP 响应的标准化映射。
- **异步任务**：继承自 `ApplicationJob` (ActiveJob) 的 Sidekiq Workers（如 `BookEpubImportWorker`, `EpubExportWorker`）负责处理耗时的 EPUB/PDF 解析、OSS 文件交互及数据库批量更新，确保主线程非阻塞。
