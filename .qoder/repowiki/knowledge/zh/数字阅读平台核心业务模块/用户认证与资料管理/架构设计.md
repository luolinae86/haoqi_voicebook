- **接口层**：基于 `Grape::API` 构建 RESTful 端点，通过 `AppUserHelpers` 封装用户创建逻辑。
- **服务层**：集成 `WechatAuthService`、`QqAuthService` 和 `AliyunSmsService` 处理第三方 OAuth 及短信验证。
- **数据层**：`AppUser` 模型管理核心身份标识（UUID、OpenID）及 VIP 状态；`HeadImg` 模型提供头像资源管理。
- **表现层**：使用 `Grape::Entity` 定义 API 响应结构，实现敏感字段过滤与关联数据（如年级名称、头像 URL）的格式化输出。
