- **接口层**：基于 Grape 框架，划分为 `leaderboards`（通用榜单）、`ranks`（年级分级排行）、`home`（首页推荐）和 `parental`（家长管控）四个 API 模块，通过 `Mount` 类进行路由挂载。
- **业务逻辑层**：采用 Helper 模块（如 `LeaderboardHelpers`, `HomeHelpers`）封装序列化与过滤逻辑；利用 `Grape::Entity`（如 `LeaderboardEntity`）实现响应数据的标准化输出。
- **数据持久层**：使用 ActiveRecord 模型管理榜单配置（`Leaderboard`）、排行内容（`Rank`）、推荐位（`Recommend`）及黑名单（`ParentalControl`）。
- **异步处理**：通过 `CalculateLeaderboardsJob` (Sidekiq) 定时执行自动榜单的统计与更新，支持按周/月阅读量等规则实时计算排名。
