name: Ruby 字符串引号规范
description: Ruby 代码中字符串默认使用单引号 ''，只有在需要字符串插值（包含变量）时才使用双引号 ""
type: feedback
---

**Rule:** Ruby 字符串默认使用单引号 `''`，只有在需要插值（如 `"#{var}"`、`"\n"` 转义字符等）时才使用双引号 `""`。

**Why:** 用户明确要求的编码风格规范，保持代码一致性。

**How to apply:**
- 纯文本字符串、哈希键名、路由路径等 → 单引号：`'hello'`, `'user_id'`, `'/api/users'`
- 包含 `#{}` 插值或 `\n` `\t` 等转义 → 双引号：`"Hello #{name}"`, `"line1\nline2"`
- 生成新代码时始终遵循此规则
- Review 代码时将不必要的双引号改为单引号
